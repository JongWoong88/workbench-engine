# 설계 문서를 쓸 때 (📐 Design)

확정된 요구사항과 채택된 제안을 받아 **정책과 기술 구조를 정하는** 문서에 적용한다. 설계 초안과 결정 기록 두 종류가 있다.

| 종류 | 답하는 것 | 파일명 (기본) |
|---|---|---|
| 설계 초안 | 무엇을 어떤 구조·규칙으로 만드는가 | `design-<주제>.md` |
| 결정 기록 | 되돌리기 어려운 선택을 왜 그렇게 했는가 | `decision-<주제>.md` |

설계가 크면 전체 설계 문서 하나와 하위 주제 문서 여럿으로 나눈다. 전체 문서는 하위 문서의 목차와 공통 전제만 가진다.

## 설계 초안

### 담을 것

- **전제** — 입력이 된 요구사항(`R-1`)·제안 결정·조사 문서를 링크한다. 여기서 요구사항을 다시 풀어 쓰지 않는다
- **범위** — 이번 설계가 다루는 것과 다루지 않는 것
- **설계 본문** — 확정되면 저장소 문서로 옮겨질 내용이다. `/workbench:documentation`의 서술 지침 형식으로 쓴다

  | 쓰는 내용 | 로드할 지침 |
  |---|---|
  | 업무 규칙·정책·상태 전이·계산식 | [../../documentation/writing/rules.md](../../documentation/writing/rules.md) |
  | 구조·흐름·데이터 모델·설계 판단 | [../../documentation/writing/structure.md](../../documentation/writing/structure.md) |
  | API 계약·대외 연동 | [../../documentation/writing/interface.md](../../documentation/writing/interface.md) |

- **현행 대비** — 기존 구현·정책을 바꾸는 설계라면 현행 / 변경 / 이유를 표로. 현행은 코드 링크로 근거를 단다
- **영향 범위** — 바뀌는 저장소·모듈·테이블·외부 연동. 호환성이 깨지는 지점은 따로 모은다
- **전환 전략** — 기존 데이터·사용자·연동을 새 구조로 옮기는 방법과 순서. 저장소 문서에는 쓸 수 없는 시점 내용이므로 여기에 쓴다
- **미결 사항** — `O-1`로 번호 매기고 누가 언제까지 결정해야 하는지. 미결이 남은 부분은 본문에서 `O-1 미결`로 표시한다. 자율 모드에서는 두지 않는다 — 안을 골라 `decisions.md`의 `D-n`으로 기록하고 본문에 링크한다

### 정책이 이미 저장소·공통 문서에 있을 때

- 정책의 정본이 저장소 문서나 이 환경의 공통 문서에 있으면, 설계 초안에는 **변경안만** 쓴다 (현행 조항 링크 → 변경 조항 → 이유)
- 정본을 설계 초안에 복제하지 않는다. 확정되면 `/workbench:documentation`으로 정본을 갱신한다

### 금지

- 작업 단위·구현 순서·일정 — `/workbench:plan`으로
- 구현 코드. 흐름을 보여주는 짧은 의사코드는 허용
- 메서드 호출 순서 옮겨 적기, 클래스·필드 전체 목록 — 코드와 DDL이 원본이면 링크

## 결정 기록

되돌리기 어려운 선택(저장소 선택, 인증 방식, 데이터 소유권, 모듈 경계)마다 하나씩 쓴다. 여러 결정을 한 문서에 모을 때는 결정마다 번호를 붙인다(`결정 1`, `결정 2`).

### 담을 것

- **상태** — `제안됨` / `채택` / `대체됨`. 대체되면 새 결정 문서를 링크한다. 원래 내용은 지우지 않는다
- **맥락** — 이 결정이 필요해진 문제와 제약(외부 제약, 기존 구현, 일정·인력)
- **결정** — 무엇을 택했는가. 한 문장으로
- **검토한 대안** — 대안마다 같은 축으로 비교하고 탈락 이유를 적는다
- **결과** — 이 선택으로 얻은 것과 **감수한 것**. 감수한 것이 없는 결정은 없다
- **남은 결정** — 이 결정으로 새로 생긴 미결 사항. 자율 모드에서는 고른 안을 `decisions.md`의 `D-n`으로 기록하고 링크한다

### 금지

- 결정 없이 대안만 나열하기 — 그건 제안서다
- 결정 후 사정이 바뀌었다고 본문을 고치기. 상태를 `대체됨`으로 바꾸고 새 결정을 쓴다
