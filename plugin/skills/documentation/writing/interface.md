# API 계약·대외 연동 규격을 쓸 때

우리가 노출하는 API, 또는 우리가 호출하는 외부 시스템(PG, 알림, 제휴사 등)과의 계약을 서술하는 섹션에 적용한다.

## 먼저 볼 것

OpenAPI·REST Docs처럼 생성된 스펙이 있으면 **그것이 원본**이다. 문서에는 스펙에 담기지 않는 것만 쓴다 — 호출 시점, 호출 순서, 재시도 판단, 상대 시스템의 특이 동작.

## 담을 것

- **인증** — 방식과 필요한 권한. 서명·해시 규칙이 있으면 알고리즘과 대상 필드
- **필드 제약** — 필수 여부, 형식, 길이, 허용값. enum은 전부
- **오류** — HTTP 상태 · 에러코드 · 의미 · **호출자 조치**(재시도 가능 여부)
- **멱등성** — 같은 요청이 두 번 오면 어떻게 되는가. 상태를 바꾸는 호출이면 반드시
- 타임아웃, 재시도 간격, 처리율 제한
- 환경별 차이 — 엔드포인트, 테스트 모드. 값은 설정 파일 링크로
- **대외 연동**이면 상대의 공식 규격 문서 링크 + 우리 쪽 해석과 주의점(규격과 실제 동작이 다른 곳, 점검 시간, 알려진 장애 패턴)

## 금지

- 설정 값·키·비밀번호 기재. **설정 키 이름**까지만 쓴다
- 생성 스펙과 중복되는 필드 표
- 서버 내부 구현과 쿼리
- 접기 남용 — 에러코드는 검색으로 도달한다
